简单选择排序代码(C/C++实现)

每趟找最小并交换，打印中间结果

方向键也可切换

要点

  • 外层 i 表示本趟要填的前端位置
  • 内层从 i+1 扫到末尾更新最小下标 k
  • k 与 i 不同才交换，再打印本趟数组
  • 不稳定，交换可能打乱相等元次序

时间最好/最坏/平均 O(n^2)；空间 O(1)；不稳定

完整 C++ 代码

下载 .cpp 

// 简单选择排序代码：每趟打印
#include <iostream>
using namespace std;

void printArr(const int a[], int n) {
    for (int i = 0; i < n; i++) {
        if (i) cout << " ";
        cout << a[i];
    }
    cout << "\n";
}

void selectSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int k = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[k]) k = j;
        }
        if (k != i) {
            int t = a[i];
            a[i] = a[k];
            a[k] = t;
        }
        printArr(a, n);  // 每趟结束后打印
    }
}

int main() {
    int a[] = {5, 2, 8, 1, 9, 3};
    int n = 6;
    printArr(a, n);
    selectSort(a, n);
    return 0;
}
